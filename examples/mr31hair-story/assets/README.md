# 이미지 에셋 가이드 (assets/)

이 웹스토리는 **사진 없이도 프리미엄 그라데이션 배경으로 완성도 있게 렌더링**됩니다.
아래 파일명으로 사진을 넣으면, 해당 페이지가 자동으로 **풀블리드 사진 배경**으로 바뀝니다.

| 파일명 | 사용 위치 | 권장 사진 (업로드해 주신 이미지 기준) |
|---|---|---|
| `mr31-01.jpg` | 1p 커버 | 모델 정면 포트레이트 (1번 이미지) |
| `mr31-02.jpg` | 4p 페르소나 / 북엔드 | 머릿결 클로즈업 (2번 이미지) |
| `mr31-03.jpg` | 북엔드 관련글 | 제품 보틀 (3번 이미지) |
| `mr31-04.jpg` | 12p 클로징 배경 | 핑크 살롱 무드 (4번 이미지) |
| `mr31-05.jpg` | 북엔드 관련글 | 핑크 살롱 무드 (5번 이미지) |

## 권장 사양
- **비율**: 세로형 9:16 (예: 720×1280 또는 1080×1920) — 풀블리드용
- **포맷**: `.jpg` (또는 코드의 src를 `.webp`로 함께 변경)
- **용량**: 페이지당 300KB 이하 권장 (모바일 로딩 최적화)

## 적용 방법
1. 위 표의 파일명 그대로 이 `assets/` 폴더에 넣습니다.
2. 끝. (HTML 수정 불필요 — `index.html`의 `amp-img src`가 이미 이 경로를 가리킵니다)

사진이 없으면 `amp-img`는 비어 있고, 각 페이지에 설정된 **웜 그라데이션 배경**이 그대로 노출됩니다.
