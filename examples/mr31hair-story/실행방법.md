# 엠알31헤어 웹스토리 — 실행 방법

이 폴더에는 두 가지 버전이 들어 있습니다.

| 파일 | 설명 | 실행 방법 |
|---|---|---|
| **preview.html** | 12페이지를 한 화면에 보여주는 스토리보드 (오프라인) | **그냥 더블클릭** — 인터넷만 되면 바로 열림 |
| **index.html** | 진짜 AMP 웹스토리 (스와이프·애니메이션·공유) | **로컬 서버 필요** (아래 런처 사용) |

---

## ✅ 가장 쉬운 방법 — 런처 더블클릭

- **Windows**: `run.bat` 더블클릭
- **macOS**: `run.command` 더블클릭  (안 열리면 → 우클릭 → 열기)
- **Linux/터미널**: `./run.sh`

→ 자동으로 로컬 서버가 켜지고 브라우저에 `http://localhost:8000/index.html` 가 열립니다.
끄려면 터미널 창에서 **Ctrl + C**.

> 모바일처럼 보려면: 브라우저에서 F12(개발자도구) → 디바이스 툴바(휴대폰 아이콘) → iPhone 등 세로 화면 선택.

---

## 🖐 수동 실행 (런처가 안 될 때)

이 폴더에서 터미널을 열고:

```bash
python3 -m http.server 8000      # (윈도우는 python -m http.server 8000)
```

그 다음 브라우저 주소창에:

```
http://localhost:8000/index.html
```

## 📌 참고

- **index.html**은 AMP 런타임을 `cdn.ampproject.org`에서 불러오므로 **인터넷 연결이 필요**합니다.
  (그래서 `file://`로 직접 열지 말고 위의 로컬 서버로 여세요.)
- **preview.html**은 인터넷 없이도 동작하지만 한글 폰트는 Google Fonts를 쓰므로
  오프라인이면 시스템 기본 글꼴로 표시됩니다.
- **사진 적용**: `assets/` 폴더에 `mr31-01.jpg` ~ `mr31-05.jpg`(세로 9:16 권장)를 넣으면
  커버·페르소나·클로징이 풀블리드 사진 배경으로 바뀝니다. (자세한 내용은 `assets/README.md`)
